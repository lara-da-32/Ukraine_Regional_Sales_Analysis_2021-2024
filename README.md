# Регіональна структура та динаміка реалізації продукції підприємств України (2021–2024)

## Опис проєкту

Проєкт присвячений аналізу обсягів реалізованої продукції підприємств України за регіонами протягом 2021–2024 років.

Мета — дослідити зміни регіональної структури реалізації, визначити регіони з найбільшим зростанням і скороченням частки та оцінити концентрацію реалізації серед провідних регіонів.

## Джерело даних

Державна служба статистики України.

Показник: «Обсяг реалізованої продукції (товарів, послуг) підприємств» у регіональному розрізі.

Період дослідження: 2021–2024 роки.

[Офіційне джерело даних — Держстат](https://stat.gov.ua/uk/topics/diyalnist-pidpryyemstv)

## Інструменти

- Microsoft Excel — підготовка, перевірка та аналіз даних, розрахунок показників.
- Tableau — створення візуалізацій та інтерактивного дашборду.
- GitHub — документація та презентація проєкту.

## Підготовка та аналіз даних

У Microsoft Excel виконано:
- перевірку та впорядкування вихідних даних;
- розрахунок абсолютних і відносних змін обсягів реалізації;
- розрахунок часток регіонів у загальному обсязі реалізації;
- визначення зміни часток у відсоткових пунктах;
- визначення регіонів із найбільшим зростанням і скороченням часток;
- порівняння сукупної частки трьох провідних регіонів.

## Основні результати

- Київ мав найбільшу частку реалізації серед регіонів протягом досліджуваного періоду.
- Частка Києва зросла з 40,49% у 2021 році до 43,37% у 2024 році — на 2,88 відсоткового пункта.
- Сукупна частка Києва, Дніпропетровської та Київської областей збільшилася з 57,07% до 60,38% — на 3,31 відсоткового пункта.
- Найбільше зростання частки серед областей продемонструвала Львівська область (+1,69 відсоткового пункта).
- Найбільше скорочення частки зафіксовано в Донецькій області (−3,77 відсоткового пункта).

Результати свідчать про посилення концентрації реалізації серед трьох провідних регіонів.
